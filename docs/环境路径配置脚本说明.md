# HTMSR 环境路径配置脚本说明

## 1. 脚本用途

`scripts/Configure-HtmsrEnvironment.ps1` 用于在不同电脑上生成本机专用的 CMake 配置，避免每台机器都直接修改仓库内的 `CMakePresets.json`。

脚本主要完成三件事：

- 生成本机依赖路径配置文件
- 根据配置文件检查 Qt、OpenCV、PCL、Eigen、MVS、VTK 等路径
- 生成 `CMakeUserPresets.json`，供 Visual Studio 和命令行 CMake 使用

## 2. 相关文件

| 文件 | 作用 |
| --- | --- |
| `scripts/Configure-HtmsrEnvironment.ps1` | 环境路径配置脚本 |
| `scripts/htmsr_environment.local.json` | 本机依赖路径配置，不建议提交到仓库 |
| `CMakeUserPresets.json` | 脚本生成的本机 CMake 预设，不建议提交到仓库 |
| `CMakePresets.json` | 仓库默认 CMake 预设，作为公共配置保留 |

## 3. 首次使用

在项目根目录执行：

```powershell
cd C:\PROJECT\HTMSR
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Configure-HtmsrEnvironment.ps1 -CreateDefault
```

脚本会生成默认配置：

```text
C:/PROJECT/HTMSR/scripts/htmsr_environment.local.json
```

打开该文件，按本机实际安装位置检查并修改。

## 4. 推荐路径配置

当前项目推荐路径如下：

```json
{
  "qtDir": "C:/ENVIORNMENT/qt/5.15.2/msvc2019_64",
  "opencvDir": "C:/ENVIORNMENT/opencv_450_vs2019",
  "pclDir": "C:/ENVIORNMENT/PCL/PCL 1.12.1",
  "eigenDir": "C:/ENVIORNMENT/ceresLib/Eigen",
  "mvsDir": "C:/ENVIORNMENT/MVS",
  "mvsRuntimeDir": "C:/Program Files (x86)/Common Files/MVS/Runtime/Win64_x64",
  "vtkDir": "",
  "enableHikCamera": true,
  "enableVtkViewer": true
}
```

说明：

- `qtDir` 指向 Qt 5.15.2 的 MSVC2019 64 位目录。
- `opencvDir` 指向 OpenCVConfig.cmake 所在安装根目录。
- `pclDir` 指向 PCL 安装根目录。
- `eigenDir` 指向 Eigen 头文件目录或 CMake 配置目录。
- `mvsDir` 指向海康 MVS SDK 安装目录。
- `mvsRuntimeDir` 指向 MVS 运行时 DLL 目录。
- `vtkDir` 可为空，优先使用 PCL 关联的 VTK；如果有独立 VTK Qt Release 版本，可填写。
- `enableHikCamera=false` 时，项目仍可编译离线流程，但不会启用真实海康相机接口。
- `enableVtkViewer=false` 时，点云视图会使用占位显示，但重建和导出仍可用。

## 5. 生成 CMakeUserPresets.json

确认 local json 后执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Configure-HtmsrEnvironment.ps1 -Configure
```

成功后会生成：

```text
C:/PROJECT/HTMSR/CMakeUserPresets.json
```

Visual Studio 打开项目后会自动识别该文件中的 local 预设。

## 6. 使用 local 预设构建

Debug：

```powershell
cmake --preset local-vs2022-x64-debug
cmake --build --preset local-debug
```

Release：

```powershell
cmake --preset local-vs2022-x64-release
cmake --build --preset local-release
```

## 7. Qt 与 VTK 的构建类型匹配

当前项目曾遇到 Release 程序误加载 Debug VTK/Qt DLL 的问题。表现通常是：

```text
QWidget: Must construct a QApplication before a QWidget
```

因此环境配置时必须注意：

- Debug 构建可以使用 Debug 版 Qt/VTK。
- Release 构建必须使用 Release 版 Qt/VTK。
- Release 程序目录中不应出现 `Qt5Cored.dll`、`Qt5Widgetsd.dll`、`vtk...d.dll`。
- 如果当前 VTK 只提供 Debug Qt 支持库，Release 会自动禁用内嵌 VTK 点云视图并退回占位显示。

这不是重建算法失败，而是可视化依赖不完整。点云仍然可以生成和导出。

## 8. 海康 MVS 配置

如果需要真实相机在线采集，需要：

1. 安装海康 MVS SDK。
2. 确认 MVS Runtime 路径存在。
3. 确认相机能在 MVS 官方工具中枚举。
4. 关闭 MVS 官方工具，避免占用相机。
5. 在 HTMSR 中点击 `刷新设备`，选择左相机和右相机。

如果另一台电脑暂时没有相机或没有 SDK，可以设置：

```json
{
  "enableHikCamera": false
}
```

这样仍然可以测试离线标定、离线重建和点云导出。

## 9. 常见问题

### 9.1 Visual Studio 看不到 local 预设

检查：

- `CMakeUserPresets.json` 是否在项目根目录。
- JSON 格式是否正确。
- Visual Studio 是否重新加载了 CMake 项目。

必要时关闭并重新打开 Visual Studio。

### 9.2 CMake 找不到 Qt

检查 `qtDir` 是否指向：

```text
C:/ENVIORNMENT/qt/5.15.2/msvc2019_64
```

目录下应包含：

```text
bin/qmake.exe
lib/cmake/Qt5
```

### 9.3 CMake 找不到 PCL 或 OpenCV

检查对应目录下是否存在 CMake 配置文件：

```text
OpenCVConfig.cmake
PCLConfig.cmake
```

如果路径只指到了源码目录或压缩包目录，CMake 无法识别。

### 9.4 程序能启动但点云视图是占位文字

说明内嵌 VTK Qt 视图未启用或构建类型不匹配。可以先继续验证标定、重建和导出；如果必须在界面中显示点云，需要安装或编译与 Qt 5.15.2、MSVC x64、当前构建类型匹配的 VTK Qt 支持库。
