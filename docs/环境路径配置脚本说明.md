# 环境路径配置脚本说明

## 1. 用途

`scripts/Configure-HtmsrEnvironment.ps1` 用于在不同电脑上快速切换 HTMSR 的第三方库路径。

它不会修改主工程的 `CMakePresets.json`，而是生成本机专用的 `CMakeUserPresets.json`。Visual Studio 和 CMake 会自动读取这个文件，因此每台电脑都可以维护自己的 Qt、OpenCV、PCL、Eigen、MVS SDK 路径。

## 2. 生成本机配置

首次在一台新电脑上使用时，在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Configure-HtmsrEnvironment.ps1 -CreateDefault
```

脚本会生成：

```text
scripts/htmsr_environment.local.json
CMakeUserPresets.json
```

其中 `scripts/htmsr_environment.local.json` 是需要手动修改的本机路径配置。

## 3. 修改路径

打开 `scripts/htmsr_environment.local.json`，按本机实际安装位置修改：

```json
{
  "qtRoot": "C:/ENVIORNMENT/qt/5.15.2/msvc2019_64",
  "opencvRoot": "C:/ENVIORNMENT/opencv_450_vs2019",
  "pclRoot": "C:/ENVIORNMENT/PCL/PCL 1.12.1",
  "eigenIncludeDir": "C:/ENVIORNMENT/ceresLib/Eigen",
  "mvsRoot": "C:/ENVIORNMENT/MVS",
  "mvsRuntimeDir": "C:/Program Files (x86)/Common Files/MVS/Runtime/Win64_x64",
  "enableHikCamera": true,
  "enableVtkViewer": true
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `qtRoot` | Qt 的 MSVC x64 根目录，当前工程使用 Qt5。 |
| `opencvRoot` | OpenCV 根目录，脚本会自动拼出 `x64/vc16/lib`。 |
| `pclRoot` | PCL 根目录，脚本会自动拼出 PCL、VTK、Boost、Qhull 的 CMake 路径。 |
| `eigenIncludeDir` | 包含 `Eigen/Core` 的 Eigen 头文件目录。 |
| `mvsRoot` | 海康 MVS SDK 根目录，包含 `Development/Includes` 和 `Development/Libraries/win64`。 |
| `mvsRuntimeDir` | 海康 MVS 运行时 DLL 目录。 |
| `enableHikCamera` | 是否启用海康相机编译，没装 SDK 时可以改为 `false`。 |
| `enableVtkViewer` | 是否尝试启用内嵌 VTK 点云视图，缺少 VTK Qt 组件时工程会退回占位视图。 |

## 4. 重新生成 CMake 本机预设

修改 JSON 后执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Configure-HtmsrEnvironment.ps1
```

脚本会检查关键路径，并重新生成 `CMakeUserPresets.json`。

## 5. 配置和构建

在 Visual Studio 中选择：

```text
local-vs2022-x64-debug
```

或在命令行执行：

```powershell
cmake --preset local-vs2022-x64-debug
cmake --build --preset local-debug
```

Release 构建使用：

```powershell
cmake --preset local-vs2022-x64-release
cmake --build --preset local-release
```

## 6. 一次性生成并配置

如果路径已经正确，可以直接让脚本生成预设后执行 CMake 配置：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Configure-HtmsrEnvironment.ps1 -Configure
```

默认配置 `local-vs2022-x64-debug`。如需指定其他 preset：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Configure-HtmsrEnvironment.ps1 -Configure -Preset local-vs2022-x64-release
```

## 7. 版本管理约定

以下文件是本机专属配置，已经加入 `.gitignore`，不要提交：

```text
CMakeUserPresets.json
scripts/htmsr_environment.local.json
```

以下文件是项目公共模板，可以提交并作为新电脑参考：

```text
scripts/htmsr_environment.example.json
scripts/Configure-HtmsrEnvironment.ps1
docs/环境路径配置脚本说明.md
```
